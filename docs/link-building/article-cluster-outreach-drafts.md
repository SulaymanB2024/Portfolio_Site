## Cluster: AI agent systems

### Draft 1: editorial source note

Subject: Evidence boundaries for businesses described as AI-run

I reviewed 30 public cases and separated live operations, bounded pilots, narrow production agents, and simulations. The resulting article shows exactly where people still supply legal authority, capital, physical work, supervision, and recovery. If you are reporting on AI-run businesses, the case table and source limitations may be useful as a reference: https://sulayman-bowles.dev/research/ai-systems/the-first-ai-managers

### Draft 2: developer discussion

I documented an AI agent evaluation harness built around versioned tasks, immutable traces, replay fixtures, independent graders, and protected promotion gates. The useful question is not whether one run scored well, but whether another reviewer can reproduce the evidence without letting the agent redefine success: https://sulayman-bowles.dev/viralbench-codex-agent-harness

## Cluster: technical SEO graphs

### Draft 1: editorial source note

Subject: Canonicals as a graph consistency problem

This article models redirects, HTML canonicals, sitemap entries, internal links, hreflang, and structured data as one directed graph. The accompanying conflict taxonomy makes split targets and cycles mechanically testable: https://sulayman-bowles.dev/research/technical-seo/canonicalization-graph-consistency

### Draft 2: checklist resource note

I converted a technical SEO migration checklist into executable release gates for status codes, canonicals, indexability, static content, schema, redirects, internal links, and sitemap membership. It is a release-control artifact rather than a ranking guarantee: https://sulayman-bowles.dev/research/technical-seo/technical-seo-migration-release-gates

## Cluster: data provenance

### Draft 1: editorial source note

Subject: A provenance-first SEO data pipeline

This systems essay connects Search Console page/query data to URL identity, collection time, raw and rendered observations, derived findings, and export state. The artifact is designed to make technical SEO decisions reviewable rather than turn them into another dashboard score: https://sulayman-bowles.dev/research/search-console/technical-seo-public-data-infrastructure
